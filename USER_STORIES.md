# User Stories

| ID | User Story | Sprint |
|----|---|---|
| US-1 | As a driver, I want to create an account, so that I can reserve parking. | 1 |
| US-2 | As a driver, I want to log in and log out safely, so that my account stays private. | 1 |
| US-3 | As a driver, I want to reset my password, so that I can get back into my account. | 1 |
| US-4 | As a driver, I want to search for parking near a place, so that I can find a spot quickly. | 1 |
| US-5 | As a driver, I want to reserve a spot for a date and time, so that it is ready when I arrive. | 1 |
| US-6 | As a driver, I want to see a map of open spots, so that I can pick the best one. | 2 |
| US-7 | As a driver, I want to cancel a reservation, so that I do not pay for a spot I cannot use. | 2 |
| US-8 | As a driver, I want a receipt and payment history, so that I can track my spending. | 3 |
| US-9 | As an operator, I want to log in to a dashboard, so that I can manage my lots. | 1 |
| US-10 | As an operator, I want to add and edit lots and spots, so that the system shows the right information. | 2 |
| US-11 | As an operator, I want to set prices, so that I can control my revenue. | 3 |
| US-12 | As an operator, I want to see daily revenue and occupancy reports, so that I can make better decisions. | 3 |
