# Smart Parking Platform — Semester Project

This repository contains the semester-long project management plan for the **Smart Parking Platform**, a fictitious software system (built by "$oftware ¢orp.") that helps drivers locate, reserve, and pay for parking in real time, with tools for parking operators to manage occupancy and pricing.

## Contents

- `PROJECT.md` — the living project document, updated weekly per assignment requirements.

## Weekly Process

Each week:
1. New content is added to `PROJECT.md` based on that week's homework assignment.
2. The document version is updated.
3. A 1–2 minute video update is recorded for stakeholders and linked on Canvas along with this repo's public link.
